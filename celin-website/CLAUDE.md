# CELIN website — notes for Claude

Fully independent Next.js 16 app (no code, data or settings shared with Task Flow or the Pars site) in a sub-folder of this repository (deployed as its own Vercel project with Root Directory `celin-website`). Luxury bilingual site of the jewellery brand **CELIN / سلین** (Etemad Gallery): Persian (RTL) at `/`, English at `/en`. Read `README.md`, `docs/SETUP_FA.md`, `docs/BRAND_BOOK_FA.md` and `docs/DESIGN_SYSTEM.md` before larger changes.

- **Languages:** two root layouts in route groups `(fa)` and `(en)`. Page bodies are shared components in `src/components/pages/*` that take `lang`; route files are thin wrappers. UI copy lives in `src/content/copy/*.ts` (`fa` / `en`, same shape); the brand's own story and lines are in `src/content/copy/story.ts` (use them, never invent claims). Persian digits via `num()` / `formatPrice()` (`src/lib/format.ts`); logical Tailwind utilities (`ms-`, `pe-`, `start-`, `end-`). No `letter-spacing` on Persian text; tracking only on Latin labels.
- **Brand:** tokens in `src/app/globals.css` (`@theme`: layered mesh grounds, `--metal-*` gradients), never raw hex in components. Persian type is Noto Naskh Arabic (headings 600–700, text 500; Vazirmatn only for UI via `font-ui`). The round **arch** is the signature frame (`<Arch>`, `ArchLines`). The logo files in `public/brand/` are vectorised 1:1 from the official logo — never redraw, recolour outside the documented variants, or distort them.
- **Effects:** `src/components/fx/*` (Lenis + GSAP smooth scroll, `useGsap`, `SplitWords` — words, never letters — `Sparkles`, `Aura` WebGL, `Reel`, `Marquee`, `Magnetic`, `Cursor`, `Intro`). Everything must stay readable without JS and honour reduced motion (OS setting and the footer toggle). Custom CSS classes live in `@layer components` so utilities win (unlayered CSS beats Tailwind utilities); an IntersectionObserver ignores a target hidden by its own clip-path, so reveal triggers sit on an unclipped wrapper.
- **Data:** server-only service-role client `db()` (`src/lib/db.ts`); tables `celin_*` with RLS on and no policies; one idempotent SQL file per change in `supabase/migrations/` (never edit a shipped one). Stock and prices change only through `celin_place_order` / `celin_set_order_status` or the admin.
- **Prices are private:** public pages are static and identical for everyone, so public catalogue objects (`src/lib/catalog-types.ts`) never carry price or stock. Pro members get them from `/api/pro/prices` (session checked on every call) through `usePriceBook()`; never put a price into HTML, RSC payloads, JSON-LD, metadata or alt text.
- **Pictures:** every design picture is a slot (`src/content/slots.ts`), every product/category picture a `celin_media` row; render them with `<Picture>` (`src/components/ui/picture.tsx`, plain `<img srcset>`, blur placeholder, focal point). Uploads are resized in the browser (`src/components/admin/resize.ts`) and stored via `/api/admin/upload`.
- **Auth:** accounts in `celin_users` (phone + password, or the Pro code as sign-in), signed cookie (`src/lib/auth.ts`); admin = account with role admin or the `ADMIN_PASSWORD` session (`src/lib/admin-auth.ts`). Every admin Server Action goes through `guard()`; every admin page calls `requireAdminPage()`; every `src/lib/admin-*.ts` / `members.ts` function calls `assertAdmin()` itself.
- **Performance:** keep public pages static (catalogue and slots are cached with tags `catalog` / `slots`, invalidated by admin changes); no third-party requests at runtime (Iran); fonts are self-hosted by `next/font`.
- Commands: `npm run typecheck` · `npm test` · `npm run build` (must pass with no env vars).
