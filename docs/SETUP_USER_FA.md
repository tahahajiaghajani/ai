# راهنمای کاربران Task Flow — از حالت ساده تا تجربه‌ی کامل

> نصب جداگانه‌ای لازم نیست: همه از **همین اپ** استفاده می‌کنند. «تجربه‌ی کامل» یعنی اپ را به کلیدهای هوش مصنوعی و GitHub **خودتان** وصل کنید.
> کلیدها رمزنگاری‌شده ذخیره می‌شوند و فقط برای کارهای خودتان استفاده می‌شوند. پروژه‌ها و فایل‌هایتان فقط در مخزن خصوصی GitHub خودتان نگه داشته می‌شوند.

---

## ۱) حالت ساده (پیش‌فرض)

بعد از ثبت‌نام و تایید حساب:

- **ثبت تسک جدید** ← در فیلد **«مسئول»** خودتان یا هر همکار دیگری را انتخاب کنید.
- **سپرده به من**: تسک‌هایی که دیگران به شما داده‌اند ← «پذیرش» ← «شروع کار» ← «انجام شد» (یا «برگشت برای اصلاح»).
- **داده‌شده توسط من**: پیشرفت تسک‌هایی که به دیگران داده‌اید ← «تایید خاتمه» یا «رد خاتمه» با توضیح.
- تسکی که به خودتان می‌دهید نیازی به پذیرش ندارد و با «خاتمه» بسته می‌شود.

## ۲) فعال کردن تجربه‌ی کامل

روی **«تجربه‌ی کامل»** (آیکون موشک) بالای صفحه بزنید ← **«فعال کن»**. به صفحه‌ی **تنظیمات** می‌روید.

| آنچه وصل کرده‌اید | آنچه کار می‌کند |
|---|---|
| هیچ | مثل حالت ساده؛ بخش‌های هوش مصنوعی غیرفعال‌اند |
| کلید هوش مصنوعی | پیش‌کار، کار اصلی و «دستور سریع» (خروجی‌ها در گفت‌وگوی تسک قابل دانلودند) |
| کلید + GitHub | همه‌چیز: پروژه‌ها، دانش، گراف و Claude Code |

> بازگشت: **تنظیمات ← حالت اپ ← رفتن به حالت ساده**. چیزی پاک نمی‌شود و هر وقت خواستید برمی‌گردید.

## ۳) وصل کردن کلید هوش مصنوعی

**تنظیمات ← کلیدها ← افزودن کلید** ← سرویس را انتخاب کنید ← کلید را پیست کنید ← **ذخیره و بررسی کلید**.

| سرویس | کجا کلید بگیرید | نکته |
|---|---|---|
| **Claude (Anthropic)** — بهترین | <https://console.anthropic.com/settings/keys> | بهترین کیفیت برای کد و ویرایش فایل؛ پرداخت به ازای مصرف |
| **Google AI Studio** — رایگان | <https://aistudio.google.com/apikey> | مدل `auto` = همیشه جدیدترین Flash رایگان، با جایگزینی خودکار هنگام پر شدن سهمیه |
| **ChatGPT (OpenAI)** | <https://platform.openai.com/api-keys> | اشتراک ChatGPT Plus کلید API نمی‌دهد |
| **Kimi (Moonshot)** | <https://platform.moonshot.ai/console/api-keys> | متن‌های خیلی بلند |
| **NVIDIA** — رایگان | <https://build.nvidia.com/settings/api-keys> | مدلی انتخاب کنید که tool calling دارد (مثلاً Kimi K2 یا Qwen Coder) |
| **OpenRouter** | <https://openrouter.ai/keys> | یک کلید برای صدها مدل؛ مدل‌های `:free` رایگان‌اند |
| سرویس دیگر سازگار با OpenAI | — | آدرس پایه (معمولاً به `/v1` ختم می‌شود) را هم وارد کنید |

سپس در زبانه‌ی **مدل‌ها**:
- **پیش‌کار**: یک مدل سریع و ارزان کافی است (مثلاً Gemini `auto`).
- **کار اصلی**: «مجری داخل اپ» با بهترین مدلی که دارید (برای کد: Claude)، یا «Claude Code» (قدم ۵).
- **دانش پروژه**: خالی = مثل پیش‌کار.

با «آزمایش» روی کارت هر کلید، یک درخواست کوتاه واقعی فرستاده می‌شود.

## ۴) وصل کردن GitHub (برای پروژه‌ها، دانش و گراف)

1. یک توکن بسازید: <https://github.com/settings/tokens/new?scopes=repo,workflow&description=Task%20Flow> ← تاریخ انقضا را انتخاب کنید ← **Generate token** ← توکن (`ghp_…`) را کپی کنید.
2. در اپ: **تنظیمات ← GitHub** ← توکن را پیست کنید ← نام مخزن را خالی بگذارید (پیش‌فرض `taskflow-workspace`) ← **اتصال و آماده‌سازی مخزن**.
3. اپ **خودش** یک مخزن خصوصی در حساب شما می‌سازد و فایل‌های لازم (ورکفلوهای GitHub Actions) را در آن قرار می‌دهد. لازم نیست مخزن دیگری را کپی یا fork کنید.

> توکن fine-grained هم کار می‌کند: یک مخزن خصوصی خالی بسازید و به توکن روی همان مخزن دسترسی Contents, Actions, Secrets, Workflows (Read & write) و Metadata (Read) بدهید؛ سپس نام مخزن را در اپ وارد کنید.

ساختار مخزن شما:

```
projects/<نام-پروژه>/          فایل‌های هر پروژه، کامل و دست‌نخورده
projects/<نام-پروژه>/.taskflow/ PROJECT.md (توضیح)، KNOWLEDGE.md (دانش)، INDEX.md (نقشه‌ی فایل‌ها)، graph/، tasks/
tasks/<کد>_<عنوان>/              سوابق تسک‌های بدون پروژه (پرامپت، پاسخ، خروجی‌ها)
```

## ۵) (اختیاری) Claude Code روی GitHub Actions

اگر اشتراک Claude (Pro/Max) دارید، کار اصلی می‌تواند با Claude Code روی مخزن خودتان اجرا شود:

```bash
npx @anthropic-ai/claude-code setup-token
```

توکن `sk-ant-oat01-…` را در **تنظیمات ← GitHub ← توکن اشتراک Claude** پیست کنید (یا کلید API Anthropic، یا دکمه‌ی «استفاده از کلید …» اگر کلید Claude را در قدم ۳ وصل کرده‌اید) ← سپس در «مدل‌ها»، موتور کار اصلی را «Claude Code» کنید.
این توکن فقط به‌صورت Secret در مخزن شما ذخیره می‌شود.

## ۶) پروژه‌ها

**پروژه‌ها ← پروژه‌ی جدید** ← نام (مثلاً `Renew`) و توضیح ← سپس در «افزودن فایل» یکی از این‌ها:

- **فایل‌ها** یا **یک پوشه** (ساختار پوشه‌ها حفظ می‌شود)
- **فایل zip**
- **مخزن GitHub** (`owner/repo`، مخزن خصوصی هم با توکن شما خوانده می‌شود)

پوشه‌هایی مثل `node_modules`، `bin`، `obj`، `dist` خودکار کنار گذاشته می‌شوند. فایل‌ها کامل ذخیره می‌شوند و برای هر فایل یک خلاصه‌ی کوتاه و نام کلاس‌ها/توابع اصلی ثبت می‌شود تا فایل درست سریع پیدا شود.

### پروژه‌های Google AI Studio

باز کردن مستقیم پروژه‌های Build در AI Studio از بیرون ممکن نیست (API عمومی ندارد). یکی از این دو راه:
1. در AI Studio از منوی پروژه **Save to GitHub** را بزنید ← در اپ «افزودن فایل ← مخزن GitHub» ← نشانی همان مخزن.
2. یا **Download** (zip) ← در اپ «افزودن فایل ← فایل zip».

از آن به بعد همه‌ی کارها روی نسخه‌ی پروژه در مخزن شما انجام می‌شود.

## ۷) کار کردن — از دسکتاپ یا موبایل

### دستور سریع (خانه، صفحه‌ی پروژه)

فقط بنویسید چه کاری روی کدام پروژه انجام شود:

> در پروژه renew فایل audit.cs باگ دارد: متد Total عضو اول را جمع نمی‌زند. پیدا و درستش کن.

اپ یک تسک برای شما می‌سازد، **پروژه و فایل‌های نام‌برده را خودش پیدا می‌کند**، مجری فایل را می‌خواند، با کمترین تغییر اصلاح می‌کند و در GitHub ثبت می‌کند. پاسخ و فایل‌های تغییرکرده در گفت‌وگوی تسک نمایش داده می‌شوند و فایل دانش پروژه به‌روز می‌شود.

### ارسال تسک به پیش‌کار / کار اصلی

در **کارها** یا صفحه‌ی تسک:
- **پرامپت** خودتان و در صورت نیاز **فایل جدید** (فقط همین‌ها به مدل فرستاده می‌شود؛ عنوان و شرح تسک فرستاده نمی‌شود).
- **پروژه‌ی مرتبط (اختیاری)**: پیش‌فرض «بدون پروژه» است و دنبال دانش نمی‌گردد. با انتخاب پروژه، توضیح، دانش و نقشه‌ی فایل‌هایش به مدل داده می‌شود؛ با نوشتن یک نام جدید، پروژه ساخته می‌شود.
- **فایل‌های مرتبط (اختیاری)**: با کمبوباکس قابل جستجو (نام فایل، خلاصه یا نام تابع).

## ۸) لیمیت‌ها

وقتی یک کلید به سقف مصرف برسد، فقط کارهای **خودتان** روی همان کلید متوقف می‌شوند و بعد از ریست خودکار ادامه پیدا می‌کنند (صف اجرا ← «تلاش دوباره الان» هم هست). برای Gemini با پر شدن سهمیه‌ی روزانه‌ی یک مدل، مدل Flash بعدی امتحان می‌شود.

## ۹) حریم خصوصی

- کلیدها رمزنگاری‌شده در پایگاه داده ذخیره می‌شوند و هرگز به مرورگر برنمی‌گردند؛ با «حذف» کامل پاک می‌شوند.
- پروژه‌ها، دانش و سوابق کارها فقط در مخزن GitHub خودتان است.
- مالک اپ برای پشتیبانی وضعیت تسک‌ها و صف را می‌بیند، اما کلیدهای شما در هیچ صفحه‌ای (حتی برای مالک) نمایش داده نمی‌شوند.
