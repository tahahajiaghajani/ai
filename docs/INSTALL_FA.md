# راهنمای نصب و راه‌اندازی TaskFlow AI

> همه‌چیز روی سرویس‌های **رایگان** و **آنلاین** اجرا می‌شود (هیچ چیز لوکال نیست):
> **Vercel** (اپ) · **Supabase** (دیتابیس، احراز هویت، فایل‌ها، زمان‌بند) · **GitHub** (فضای کار، اجرای Claude) · **Google AI Studio** (Gemini) · **Claude Pro/Max** (Claude Code)
>
> زمان تقریبی: ۳۰ تا ۴۵ دقیقه.

---

## ⚠️ قبل از هر کاری: امنیت

در پیام اولیه، رمز عبور Gmail و کلید Google AI Studio را در متن چت نوشته بودید.

1. **رمز حساب Google را همین حالا عوض کنید** و احراز هویت دومرحله‌ای (2-Step Verification) را روشن کنید: <https://myaccount.google.com/security>. این اپ به رمز Gmail شما نیاز ندارد و از آن استفاده نشده است.
2. در Google AI Studio یک **کلید API جدید** بسازید و کلید قبلی را حذف کنید؛ کلید جدید را فقط در Vercel وارد کنید (مرحله‌ی ۴).
3. هیچ کلید یا رمزی را داخل کد یا مخزن GitHub ننویسید؛ همه در «Environment Variables» ی Vercel یا «Secrets» ی GitHub ذخیره می‌شوند.

## ۱) Supabase — ساخت پروژه و اجرای کوئری کامل دیتابیس

1. به <https://supabase.com> بروید و با GitHub وارد شوید.
2. **New project** را بزنید:
   - Name: `taskflow`
   - Database Password: یک رمز قوی بسازید و **جایی امن ذخیره کنید** (برای migration خودکار لازم می‌شود).
   - Region: نزدیک‌ترین منطقه (مثلاً `Central EU (Frankfurt)`).
   - Plan: **Free**
3. صبر کنید تا پروژه آماده شود (۱–۲ دقیقه).
4. از منوی سمت چپ **SQL Editor** را باز کنید ← **New query** (یا دکمه‌ی `+`).
5. فایل [`supabase/migrations/20260925000000_init.sql`](../supabase/migrations/20260925000000_init.sql) را از مخزن باز کنید (در GitHub روی دکمه‌ی **Raw** یا **Copy raw file** بزنید)، **کل محتوا** را کپی و در ویرایشگر SQL پیست کنید.
6. دکمه‌ی **Run** (یا `Ctrl/⌘ + Enter`) را بزنید.
7. باید پیام **`Success. No rows returned`** را ببینید. این کوئری همه‌چیز را یکجا می‌سازد:
   - جدول‌ها (تسک‌ها، صف کارها، لاگ زنده، فایل‌ها، پایگاه دانش، پرامپت‌ها، ارتقاها، اعلان‌ها…)
   - امنیت سطر (RLS) — هر تسک‌دهنده فقط تسک‌های خودش را می‌بیند
   - صف اتمیک کارها (جایگزین Celery)، جستجوی معنایی pgvector، زمان‌بند pg_cron
   - باکت خصوصی فایل‌ها و Realtime
   > اجرای دوباره‌ی این کوئری بی‌خطر است (ایدمپوتنت).
8. **کلیدها را بردارید:** Project Settings (چرخ‌دنده) ← **API Keys** (و Data API):
   - `Project URL` ← برای `NEXT_PUBLIC_SUPABASE_URL`
   - کلید **anon / publishable** ← برای `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - کلید **service_role / secret** ← برای `SUPABASE_SERVICE_ROLE_KEY` (محرمانه — هرگز جایی منتشر نکنید)

## ۲) Supabase — تنظیم احراز هویت

1. **Authentication → Sign In / Providers → Email**:
   - **Enable Email provider**: روشن
   - **Confirm email**: **خاموش** کنید (سرویس ایمیل رایگان Supabase فقط به اعضای تیم خودتان ایمیل می‌فرستد؛ تایید حساب تسک‌دهنده‌ها داخل خود اپ و توسط شما انجام می‌شود).
   - Save
2. **Authentication → URL Configuration** (بعد از مرحله‌ی ۴ که آدرس اپ را دارید):
   - **Site URL**: `https://<نام-شما>.vercel.app`
   - **Redirect URLs**: `https://<نام-شما>.vercel.app/**`

## ۳) GitHub — کد و توکن

### ۳-الف) قرار دادن کد روی شاخه‌ی اصلی
کد روی شاخه‌ی `claude/multi-agent-task-automation-dve2pe` در مخزن `tahahajiaghajani/ai` است. آن را با یک Pull Request در شاخه‌ی `main` ادغام کنید (Vercel و بخش «ارتقا» از `main` استفاده می‌کنند):
- در GitHub روی **Compare & pull request** ← **Create pull request** ← **Merge pull request**.

### ۳-ب) ساخت توکن دسترسی (Personal Access Token)
1. <https://github.com/settings/tokens> ← **Generate new token (classic)**
2. Note: `TaskFlow AI` · Expiration: یک سال (یا No expiration)
3. دسترسی‌ها (Scopes): تیک **`repo`** و **`workflow`**
4. **Generate token** و توکن (`ghp_…`) را کپی کنید ← برای `GITHUB_TOKEN`

> اپ با این توکن مخزن خصوصی `ai-workspace` را می‌سازد، فایل‌های تسک‌ها را commit می‌کند، ورکفلوهای Claude را اجرا می‌کند و secrets لازم را خودش تنظیم می‌کند.
>
> اگر توکن fine-grained ترجیح می‌دهید: دسترسی «All repositories» با مجوزهای Administration, Contents, Actions, Secrets, Workflows, Pull requests (Read & write) و Metadata (Read).

## ۴) Vercel — استقرار و زیردامنه‌ی رایگان

1. به <https://vercel.com> بروید و با **GitHub** وارد شوید (پلن **Hobby** رایگان).
2. **Add New… → Project** ← مخزن `ai` را **Import** کنید (اگر نمی‌بینید: «Adjust GitHub App Permissions» و دسترسی به مخزن را بدهید).
3. Framework Preset خودکار **Next.js** است؛ Build Command و Output را تغییر ندهید.
4. بخش **Environment Variables** را باز کنید و این‌ها را اضافه کنید:

| Name | Value |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL از Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | کلید anon/publishable |
| `SUPABASE_SERVICE_ROLE_KEY` | کلید service_role/secret |
| `ADMIN_EMAIL` | ایمیل خودتان (همان Gmail) — با آن مدیر می‌شوید |
| `GEMINI_API_KEY` | کلید **جدید** Google AI Studio |
| `GITHUB_TOKEN` | توکن مرحله‌ی ۳-ب |
| `GITHUB_OWNER` | `tahahajiaghajani` |
| `GITHUB_APP_REPO` | `ai` |
| `GITHUB_WORKSPACE_REPO` | `ai-workspace` |
| `CRON_SECRET` | یک رشته‌ی تصادفی طولانی (مثلاً ۶۴ کاراکتر از <https://1password.com/password-generator>) |

5. **Deploy** را بزنید و ۱–۲ دقیقه صبر کنید.
6. **گرفتن زیردامنه‌ی رایگان:** Project ← **Settings → Domains** ← روی دامنه‌ی `….vercel.app` بزنید ← **Edit** ← یک نام دلخواه و آزاد بنویسید، مثلاً `taha-tasks` ← Save. آدرس اپ شما می‌شود: **`https://taha-tasks.vercel.app`**
   (رایگان است و گواهی HTTPS هم خودکار صادر می‌شود. اگر بعداً دامنه‌ی شخصی خریدید، همین‌جا Add Domain کنید.)
7. (پیشنهادی) یک متغیر دیگر اضافه کنید: `APP_URL` = `https://taha-tasks.vercel.app` و از تب **Deployments** روی آخرین استقرار **Redeploy** بزنید.
8. به مرحله‌ی ۲-۲ برگردید و Site URL را در Supabase تنظیم کنید.

> اگر هنوز متغیری جا مانده باشد، اپ صفحه‌ی «اپ هنوز تنظیم نشده است» را با فهرست متغیرهای ناقص نشان می‌دهد.

## ۵) اولین ورود و راه‌اندازی خودکار (از داخل اپ)

1. به `https://<نام-شما>.vercel.app/signup` بروید و با **همان ایمیل `ADMIN_EMAIL`** ثبت‌نام کنید ← به‌صورت خودکار **مدیر** می‌شوید و «ورکفلو زنده» را می‌بینید.
2. به **تنظیمات و اتصال‌ها** بروید. بخش «وضعیت اتصال‌ها» باید همه را سبز نشان دهد (به‌جز مواردی که در ادامه فعال می‌کنید).
3. **۱) فعال‌سازی زمان‌بند** ← «هر ۳۰ ثانیه» ← **فعال‌سازی**.
   (Supabase از این به بعد با pg_cron هر ۳۰ ثانیه ورکر اپ را روی Vercel صدا می‌زند؛ این جایگزین Celery beat است.)
4. **۲) راه‌اندازی مخزن کاری** ← دکمه‌ی **راه‌اندازی / همگام‌سازی قالب**:
   مخزن خصوصی `ai-workspace` ساخته می‌شود، ورکفلوهای Claude/graphify و CLAUDE.md در آن کپی می‌شوند و secrets (`TASKFLOW_RUNNER_SECRET`، `TASKFLOW_APP_URL`، `GEMINI_API_KEY`) تنظیم می‌شوند.

## ۶) اتصال Claude (کار اصلی و ارتقای خودکار)

Claude Code به‌صورت headless روی **GitHub Actions** اجرا می‌شود و از اشتراک Claude شما استفاده می‌کند.

1. **ساخت توکن اشتراک (یک بار):** روی هر کامپیوتری که Node.js دارد:
   ```bash
   npx @anthropic-ai/claude-code setup-token
   ```
   مرورگر باز می‌شود؛ با حساب Claude (Pro یا Max) وارد شوید. توکنی که با `sk-ant-oat01-…` شروع می‌شود را کپی کنید (یک سال اعتبار دارد).
   > جایگزین: اگر ترجیح می‌دهید هزینه جدا حساب شود، از <https://console.anthropic.com> یک `ANTHROPIC_API_KEY` بسازید.
2. در اپ ← **تنظیمات ← ۳) اتصال Claude** ← توکن را در `CLAUDE_CODE_OAUTH_TOKEN` پیست کنید.
3. (اختیاری ولی پیشنهادی) برای اینکه ارتقاهایی که دیتابیس را تغییر می‌دهند خودکار روی Supabase اعمال شوند:
   Supabase ← دکمه‌ی **Connect** (بالای صفحه) ← **Session pooler** ← رشته‌ی اتصال را کپی کنید و `[YOUR-PASSWORD]` را با رمز دیتابیس مرحله‌ی ۱ جایگزین کنید ← در فیلد `SUPABASE_DB_URL` پیست کنید.
4. **ذخیره در GitHub Secrets** را بزنید. (توکن در دیتابیس اپ ذخیره نمی‌شود؛ مستقیماً رمزنگاری و در GitHub قرار می‌گیرد.)
5. «وضعیت اتصال‌ها» را Refresh کنید؛ همه باید سبز باشند.

## ۷) تسک‌دهنده‌ها و موبایل

- **لینک ثبت‌نام تسک‌دهنده‌ها:** `https://<نام-شما>.vercel.app/signup` — بعد از ثبت‌نام، در **کاربران** تایید کنید. یا از همان صفحه **ساخت حساب تسک‌دهنده** را بزنید و ایمیل/رمز را به فرد بدهید.
- تسک‌دهنده‌ها فقط «پنل تسک‌دهنده» را می‌بینند: ثبت تسک و تسک مرتبط، وضعیت و درصد پیشرفت زنده، برگشت/ارسال مجدد، تایید یا رد خاتمه.
- **نصب روی موبایل (مثل یک اپ):**
  - iPhone (Safari): دکمه‌ی Share ← **Add to Home Screen**
  - Android (Chrome): منوی ⋮ ← **Install app / Add to Home screen**
  - اعلان‌های مرورگر: با اولین باز کردن زنگوله‌ی اعلان‌ها اجازه بدهید.

## اولین تست کامل

1. از **ثبت تسک** یک تسک آزمایشی ثبت کنید (مثلاً «طراحی جدول کاربران و نقش‌ها برای پنل مدیریت شعب»).
2. در **کارتابل** ← «در انتظار تایید» ← **تایید**.
3. در «صف پیش‌کار» تسک را انتخاب ← **ارسال به پیش‌کار** ← پرامپت (و در صورت نیاز فایل) ← **شروع پیش‌کار**.
4. به **ورکفلو زنده** بروید: تسک در گره‌ی «در حال انجام پیش‌کار» است و ورکفلوی کوچک ۸ مرحله‌ای (آماده‌سازی ← تحقیق ← WBS ← روش انجام ← اجرای کارهای ساده ← گزارش ← استخراج دانش ← انتشار در GitHub) زنده جلو می‌رود. روی تسک بزنید تا لاگ زنده (افکار Gemini، فایل‌های ساخته‌شده، commitها) را ببینید.
5. پس از اتمام، تسک در «صف انجام کار اصلی» است ← **ارسال به Claude** ← لاگ زنده‌ی Claude («اجرای دستور…»، «ایجاد فایل…») و فهرست کارهای (Todo) او را ببینید.
6. خروجی نهایی در `ai-workspace/tasks/<کد>_<عنوان>/final/` با `EXPLANATION.md` و `FILES.md`.
7. **اعلام خاتمه** ← تسک‌دهنده تایید یا رد می‌کند.
