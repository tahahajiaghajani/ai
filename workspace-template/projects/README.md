# پروژه‌ها

هر پروژه یک پوشه است: `projects/<نام-لاتین>/`

- فایل‌های پروژه (کد، مستندات، داده) **کامل و دست‌نخورده** همین‌جا هستند؛ هیچ فایلی تکه‌تکه ذخیره نمی‌شود.
- `projects/<نام>/.taskflow/` اطلاعات اپ درباره‌ی پروژه است و جدا از فایل‌های پروژه نگه داشته می‌شود:
  - `PROJECT.md` — نام، توضیحات و نکته‌هایی که هنگام ساخت پروژه نوشته‌اید
  - `KNOWLEDGE.md` — دانش انباشته‌ی پروژه (یک فایل؛ پس از هر کار به‌روز می‌شود)
  - `INDEX.md` — نقشه‌ی فایل‌ها: مسیر، نوع، خلاصه و نمادهای مهم هر فایل
  - `tasks/<کد تسک>/` — سابقه‌ی هر کار روی این پروژه (پرامپت، دستور کار، پاسخ)
  - `graph/` — گراف graphify (در صورت فعال بودن)
