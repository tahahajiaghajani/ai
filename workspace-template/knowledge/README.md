# پایگاه دانش

هر فایل یک مورد دانش قابل استفاده‌ی مجدد است که به صورت خودکار از پیش‌کار و کار اصلی تسک‌ها استخراج شده:

| پوشه | محتوا |
|---|---|
| `snippet/` | قطعه‌کدها، کوئری‌ها و اسکریپت‌های قابل استفاده‌ی مجدد |
| `workflow/` | فرایندها و ورکفلوهای قابل تکرار |
| `lesson/` | درس‌های آموخته و ترفندها |
| `dead_end/` | رویکردهایی که جواب ندادند (برای جلوگیری از تکرار بن‌بست) |
| `prompt/` | پرامپت‌هایی که نتیجه‌ی خوب دادند |
| `decision/` | تصمیم‌های فنی و دلیل آن‌ها |
| `reference/` | منابع و مستندات مفید |
| `requester_profile/` | نحوه‌ی کار با هر تسک‌دهنده |
| `notebooklm/` | بسته‌ی تجمیعی برای افزودن به NotebookLM (روزانه به‌روز می‌شود) |

همین دانش در Supabase (pgvector) نیز ذخیره شده و ایجنت‌ها قبل از هر کاری در آن جستجوی معنایی می‌کنند.
