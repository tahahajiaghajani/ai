# TaskFlow Workspace — راهنمای Claude

این مخزن «فضای کار» اپلیکیشن **TaskFlow AI** است. هر تسک یک پوشه در `tasks/` دارد و خروجی ایجنت‌های Gemini (پیش‌کار) و Claude (کار اصلی) با دیتا مپینگ دقیق در آن ذخیره می‌شود.

## ساختار

```
tasks/<کد>_<عنوان>/
  README.md            ← خلاصه، تکرارها و جدول نقشه‌ی فایل‌ها
  manifest.json        ← دیتا مپینگ ماشینی: نقش، تولیدکننده، وابستگی هر فایل
  HISTORY.md           ← تاریخچه‌ی مراحل
  iterations/NN_<عنوان>/
    request.md         ← درخواست تسک‌دهنده
    PROMPT-*.md        ← دستورهای مدیر
    CONTEXT-main.md    ← دانش بازیابی‌شده از پایگاه دانش (RAG) برای کار اصلی
    inputs/            ← فایل‌های پیوست
    prework/           ← 01-research, 02-wbs, 03-methods, 04-execution/, 05-report
  final/               ← خروجی نهایی کار اصلی (زنده؛ با هر تغییر به‌روز می‌شود)
    EXPLANATION.md  CHANGELOG.md  FILES.md
  graphify-out/        ← گراف دانش فایل‌ها (graph.json, GRAPH_REPORT.md)
  .claude-session/     ← جلسه‌ی Claude برای ادامه‌ی پروژه در تسک‌های مرتبط
knowledge/<نوع>/*.md   ← پایگاه دانش قابل استفاده‌ی مجدد (منبع NotebookLM)
```

## قوانین کار

1. **اول نقشه را بخوان، بعد فایل‌ها را:** `README.md` و `manifest.json` تسک، سپس `graphify-out/GRAPH_REPORT.md` (اگر هست). برای پیدا کردن چیزها از `graphify query "<پرسش>"` (داخل پوشه‌ی تسک) استفاده کن، نه جستجوی کور — تا توکن هدر نرود.
2. **از تجربه‌های قبلی استفاده کن:** `CONTEXT-main.md` را بخوان و برای جستجوی بیشتر در پایگاه دانش:
   `node .github/scripts/taskflow.mjs kb "پرسش"`
3. **پیش‌کار را دور نریز:** خروجی‌های `prework/` (به‌ویژه `05-report.md`) نقطه‌ی شروع توست؛ کار انجام‌شده را تکرار نکن.
4. **خروجی نهایی فقط در `final/`** همان تسک، همراه با:
   - `EXPLANATION.md` (فارسی: چه شد، چطور استفاده/اجرا شود، تصمیم‌ها، محدودیت‌ها)
   - `CHANGELOG.md` (یک ورودی برای هر مرحله/تسک مرتبط)
   - `FILES.md` (جدول دیتا مپینگ: مسیر | نقش | توضیح | وابسته به | منبع در پیش‌کار)
5. **TodoWrite** را در ابتدای کار بساز و مرتب به‌روز کن؛ مدیر آن را زنده در موبایل می‌بیند.
6. **commit/push نکن**؛ runner این کار را انجام می‌دهد. پوشه‌های تسک‌های دیگر را تغییر نده.
7. زبان توضیحات فارسی؛ کد، نام فایل‌ها و دستورات انگلیسی.
8. حوزه‌ی کاری: اپلیکیشن‌های مدیریتی برای بانک‌ها → امنیت، محرمانگی داده و لاگ ممیزی را رعایت کن و هیچ داده‌ی واقعی مشتری یا رمز را در مخزن ننویس.

## کار دستی
اگر مدیر مستقیماً (مثلاً از Claude Code تحت وب) روی این مخزن کار می‌کند، همین قوانین برقرار است؛ تغییرات push‌شده به صورت خودکار در لاگ تسک در اپ ثبت می‌شوند.
