# فضای کار TaskFlow AI

این مخزن به صورت خودکار توسط اپلیکیشن **TaskFlow AI** مدیریت می‌شود.

- `tasks/` — یک پوشه برای هر تسک (خروجی پیش‌کار Gemini و کار اصلی Claude با دیتا مپینگ دقیق)
- `knowledge/` — پایگاه دانش قابل استفاده‌ی مجدد (کدها، ورکفلوها، درس‌ها، نحوه‌ی کار با هر تسک‌دهنده) — مناسب برای افزودن به NotebookLM
- `.github/workflows/` — اجرای Claude Code، graphify و ثبت تغییرات دستی

> فایل‌های `.github/` و `CLAUDE.md` از قالب اپ کپی می‌شوند؛ برای به‌روزرسانی از صفحه‌ی «تنظیمات» اپ، «همگام‌سازی قالب» را بزنید.
