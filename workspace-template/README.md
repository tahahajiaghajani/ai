# فضای کار TaskFlow AI

این مخزن شخصی شماست و توسط اپلیکیشن **TaskFlow AI** مدیریت می‌شود. همه‌ی دانش، پروژه‌ها و خروجی‌های کارهای شما اینجا ذخیره می‌شود.

- `projects/` — پروژه‌های شما (کد و مستندات، فایل‌ها کامل) به همراه دانش و نقشه‌ی هر پروژه در `.taskflow/`
- `tasks/` — تسک‌هایی که به پروژه‌ای وصل نیستند
- `.github/workflows/` — اجرای Claude Code و graphify در GitHub Actions همین مخزن

> فایل‌های `.github/` و `CLAUDE.md` از قالب اپ کپی می‌شوند و با به‌روزرسانی اپ خودکار به‌روز می‌شوند.
