## Overview

### BMC Helix (ServiceOps platform)
- **Company context.** BMC announced in October 2024 that it would split into two independent companies: "BMC" (mainframe, Control-M/automation) and **BMC Helix** (ITSM + ITOM "ServiceOps" software); the units operate independently from 2025. An EMA brief reports that private-equity firm Montagu agreed to buy a majority stake in BMC Helix from KKR (subject to approvals; closing status unverified). Helix product pages on bmc.com now redirect to **helixops.ai**, and the versioned documentation is served from **docs.helixops.ai** (mirror of docs.bmc.com xwiki).
- **Portfolio relevant to ITSM.** BMC Helix ITSM (Service Desk: Incident + Problem; Change Management; Release Management; Asset Management; Knowledge Management; Service Request Management (SRM); Service Level Management (SLM); ITSM Insights; Smart IT legacy agent UI and the newer Helix ITSM progressive web UI), BMC Helix Digital Workplace (self-service + Catalog), BMC Helix Business Workflows (HR/Facilities/Legal/Finance case management), BMC HelixGPT (agentic AI framework + Agent Studio), BMC Helix CMDB, BMC Helix Discovery, BMC Helix AIOps, BMC Helix Operations Management, BMC Helix Log Analytics, BMC Helix Intelligent Automation, BMC Helix Continuous Optimization, BMC Helix Dashboards, BMC Helix Innovation Suite / Innovation Studio (low-code platform), BMC Helix Multi-Cloud Broker (ticket brokering), BMC Helix iPaaS powered by Jitterbit, BMC Helix Field Service Management, BMC Helix Telco Extensions, BMC Helix Knowledge Management by ComAround, Innovation Suite Knowledge Management.
- **Release train (YY.N).** 25.1 → 25.2 → 25.3 → 25.4 (umbrella release notes dated 20 Nov 2025) → **26.1.00** (30 Jan 2026), 26.1.01 (2 Mar 2026) → **26.2.00** (21 Apr 2026), 26.2.01 (29 May 2026 SaaS / 8 Jun 2026 on-prem) → **26.3.00** (21 Jul 2026), **26.3.01** (22 Sep 2026 SaaS; on-prem patch 23 Sep 2026). As of November 2026 the latest generally available line is **26.3.01** (a 26.4 release is expected but unverified). HelixGPT follows the same numbering (HelixGPT 26.3.00 July 2026, 26.3.01 Sep 2026).
- **Delivery & UI generations.** SaaS (BMC Helix cloud) and on-premises (containerized Helix platform, unverified for exact packaging). Three agent UIs coexist: the classic **Mid Tier** (AR System web client), **Smart IT** (legacy social/agent UI, being superseded), and the **BMC Helix ITSM Progressive Web Application (PWA, "universal client")** that receives most new features (progressive list loading, character menus, persisted table settings, Froala rich-text editor).
- **Frameworks embodied.** ITIL-aligned out-of-the-box processes (incident, problem, change with Forward Schedule of Changes and CAB, release, asset/configuration, knowledge, request, service level), **KCS** (built-in Knowledge-Centered Service; KCS v6 verification in Business Workflows knowledge), **5 Whys** RCA (problem investigations, AIOps "Run 5 Whys"), CMDB Common Data Model (DMTF CIM-derived, unverified), post-incident reviews (PIR) and major incident reports (MIR).
- **Licensing/tiers (as far as public docs show).** Digital Workplace capabilities are flagged by license level (Basic vs **Advanced** vs **External**; Catalog requires Advanced); HelixGPT agents need HelixGPT entitlement and an integrated model; Change Risk Advisor needs both BMC Helix Service Management and BMC Helix AIOps licenses; many new AI features ship first as **Controlled Availability (CA)** or "early access". Classic AR-System user licensing (Read / Restricted Read / Fixed / Floating) still underlies on-prem deployments (unverified for SaaS).

### ManageEngine ServiceDesk Plus (SDP)
- **Vendor & variants.** ManageEngine (Zoho Corporation). Variants: **SDP Cloud** (SaaS, continuous delivery, data centers named in 2025-2026 release notes include US, EU, IN, AU, UK, CN, UAE, Saudi Arabia, Singapore), **SDP On-Premises** (Windows or Linux, PostgreSQL or MS SQL, service-pack upgrades via .ppm files). Sister products: **SDP MSP** (multi-tenant edition for MSPs), **AssetExplorer Cloud** (launched Sep 2024 as successor to the Asset edition), Analytics Plus, Endpoint Central.
- **Editions.** **Standard** = IT help desk (incident, SLA, KB, self-service portal, reports, multi-site, scheduler, AD/LDAP); **Professional** = Standard + asset management (auto discovery, agent-based and distributed scans, purchase, contracts; CMDB as add-on); **Enterprise** = Professional + problem, change (types Standard/Minor/Major/Significant, CAB, forward schedule, change calendar), release, CMDB, IT project management, service request approvals, CTI. Problem/change/release/project/service-request-approval are **add-ons** for Standard/Professional; Password Reset Tool and Fail Over Service are add-ons for all; Remote Control via unified agent is an add-on (Professional/Enterprise). On-prem price points published on the edition page: Standard free up to 5 technicians, paid from US$1,195/yr (10 technicians); Professional from US$495/yr (2 technicians + 250 nodes); Enterprise from US$1,195/yr (2 technicians + 250 nodes). Cloud prices are per technician per month and vary by source (e.g., about US$13 Standard / US$27 Professional reported by ManageEngine, unverified for late 2026). Several AI features are Enterprise-only (Zia Agents, Zia Cluster Analysis, sentiment analysis in some DCs) while Ask Zia, Solution Assist and Workflow Assist were extended to all editions during 2025-2026.
- **Latest versions.** On-Premises build **16030** (4 Nov 2026); build 16000 (23 Sep 2026) introduced Base Site, asset acknowledgments, My Assets, QR labels, Zia-powered global search, multi-LLM support, Writing Assistant, Travel and Finance service desk instances. Cloud: continuous weekly/biweekly releases; latest noted update **3 Nov 2026** (Zia SLA breach prediction with confidence levels, AI Insights panel on request details, SharePoint as an Ask Zia knowledge source, global/individual report settings).
- **Frameworks embodied.** ITIL 4 practices (incident, service request, problem, change enablement with 8-stage lifecycle incl. CAB/UAT/Release, release, knowledge, IT asset, service configuration/CMDB, project, service level, catalog), ESM (up to 50 service desk instances), 5 Whys and fishbone RCA, PIR, CSAT/NPS surveys. Historically PinkVERIFY-certified for ITIL processes (unverified for current versions).

## Module: platform

### Features
- **Record/form engine (AR System lineage)** — every ITSM object is a form ("record definition") of numbered fields; core fields drive behavior (Submitter = field 2, Assignee = field 4, Assignee Group = field 112 used for row-level security, Assignee Group Parent = field 60989). Server workflow historically uses filters (server-side), active links (client-side) and escalations (time-based) (workflow object names unverified for SaaS), [BMC Innovation Suite].
- **Innovation Studio (low-code)** — business analysts/developers build record definitions, associations, named lists, rules, views (view designer) and processes (graphical process designer) and package them as deployable bundles; coded extensions use the Java/Angular SDK (SDK details unverified). The **IS RD Agent** (HelixGPT, CA) creates record definitions and process definitions from a conversation, [BMC Innovation Suite] [AI].
- **Agent UIs** — Mid Tier (classic consoles: Incident/Problem/Change/Asset/Knowledge Management consoles, flashboards), Smart IT (ticket console, Smart Recorder, activity feed, swarming; legacy), and the Progressive Web Application "universal client" with: progressive data loading on scroll (26.2), persisted table settings (26.1), character menus (26.3), resizable Activity pane (26.3), Froala as default rich-text editor (26.1), prioritized frequently used filter options (25.4), **Shared Ticket Console** with complex filter expressions across ticket types (25.4), [BMC Helix ITSM].
- **Activity timeline / work notes** — every ticket carries a timeline of activity notes, work info, email exchanges, system notes (e.g., automatic work-info note on status change from consoles) and AI results (Change Coordinator posts its reports as activity notes); attachments on activity notes are mined by Service Collaborator (26.3), [BMC Helix ITSM].
- **Email engine** — inbound rule-based email engine creates/updates tickets; since 25.4 it no longer creates duplicate incidents from the same email thread (adds activity notes to the original instead); email templates for sending from incidents (26.2); reply to an email directly from an incident activity note (26.2); outbound notification templates per event (unverified detail), [BMC Helix ITSM].
- **Approval engine (AR System Approval Server)** — approval processes attached to request phases; change approval phases (Review, Business Approval, Implementation Approval, Close Down) are skipped automatically when no approvers are mapped; alternates can approve on behalf; ad hoc approvers can be added; **Approval Central** console and process types such as Level, Ad hoc, Parent-Child, One-must-sign / All-must-sign, rule-based (process type names unverified), [BMC Helix ITSM].
- **Assignment engine** — automatic routing of incidents/changes/work orders to support groups and individuals using assignment mappings (company, location, operational and product categorization) and assignment methods round robin / load balancing by number or capacity (unverified), [BMC Helix ITSM].
- **Categorization model** — three-tier Operational categorization, three-tier Product categorization (+ product name, model/version), Resolution categorization; used for templates, routing, reporting, SLM terms (unverified detail), [BMC Helix ITSM].
- **Templates** — incident templates (prefill any field incl. assignment and categorization; surfaced via "Recommended Template" search in Smart Recorder), change templates with task and task-group templates, work order templates, release templates (unverified details), [BMC Helix ITSM].
- **Search** — global/ticket search; similarity-based agentic search that finds similar tickets even when the query includes status/priority criteria (26.3; indexes rebuilt after upgrade); conversational ticket search via Service Collaborator; DocuAssistant help assistant for logged-in users (26.1), [BMC Helix ITSM] [AI].
- **Localization** — user-settable locale, time zone and date formats from the UI (25.4); localized PIR labels/messages/statuses (26.3); knowledge real-time translation (ComAround/IS KM), [BMC Helix ITSM].
- **Bulk data** — spreadsheet bulk import of incident impacted areas with server-side validation and clear error records (26.3.01); Data Management/Data Wizard for foundation and CI loads (unverified), [BMC Helix ITSM].
- **Mobile** — BMC Helix mobile apps (Android/iOS) for approvals, tickets and notifications (feature list unverified); mobile-browser asset scanning that auto-populates asset details (26.1), [BMC Helix ITSM].
- **Security configuration** — attachment security (blocked file types), Content Security Policy in Central Configuration, HTTP Strict-Transport-Security, Openfire chat cross-domain policy, TLS 1.2 recommended for the Android app, [BMC Helix ITSM].
- **Record form engine (SDP)** — every module (requests, problems, changes, releases, projects, assets, CIs, solutions, purchases, contracts, custom modules) has a layout designer: drag-and-drop single/double-column sections, flexible columns up to 12 fields per row, per-section/field styling, help text, "visible to requester", PII marking + field encryption, separate technician and requester layouts (request details layout per persona, Nov 2025), focused view hiding empty fields, [SDP].
- **Additional fields (UDFs)** — Single Line, Multi Line, Numeric, Decimal, Pick List, Multi Select, Radio, CheckBox, Date/Time, Date (time-zone-free, pre-1970), Currency, Percentage, IP address, Attachment, Lookup (reference entities: Requester, Technician, Region, Vendor, Technician Group, Asset, CMDB, Project, Site, custom module), Multi-select lookup; limits raised repeatedly (e.g., 250 additional fields per product type), [SDP].
- **Field and Form Rules** — rule events On Form Load, On Field Change, On Form Submit; actions Show/Hide, Enable/Disable, Mandate, Optional fields, Execute Script; optional criteria per action; available for requests, problems, changes (across stages), releases, custom modules and custom widgets, [SDP].

### Implementation notes
- Use one **SLA policy engine** for all record types: `sla_policy` (criteria, calendar, order, site/company scope) → `sla_target` (metric: first_response, resolution, custom; goal duration; warning %) → `escalation_step` (offset before/after, actions). ### Implementation notes
