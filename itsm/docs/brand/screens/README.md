# پیش و پس از برند «کاریز»

شش صفحهٔ کلیدی در روشن، تیره و گوشی؛ گرفته‌شده با `node scripts/ui-shots.mjs` روی دادهٔ نمونه (پیش: `c0db34c`، پس: شاخهٔ `itsm-brand`).

در «پیش»، ترتیب لایه‌های CSS در مرورگر به‌هم ریخته بود (`components, utilities, …, base, antd`): پیش‌فرض‌های Tailwind همهٔ فاصله‌ها و سبک‌های سامانهٔ طراحی را صفر می‌کرد و antd بر همه چیره بود. «پس» همان صفحه‌هاست با ترتیب درست لایه‌ها (اعلام درون‌خطی در `index.html`) و برند کاریز: نشانه و نام، فیروزه برای کنش، لاجورد برای آگاهی، شب برند در ورود. بازطراحی خود صفحه‌ها گام بعد است.
