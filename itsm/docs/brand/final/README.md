# «کاریز» — نسخهٔ نهایی

صفحه‌های کلیدی نسخهٔ نهایی پس از ادغام برند با همهٔ بخش‌ها (ورود با حساب سازمانی و ویندوز، امنیت ورود و نشست‌ها، نسخهٔ سرور، خدمات سازمانی و میدانی، سطح خدمت و نیروی کار، مدیریت و اتصال‌ها) در روشن و تیره ۱۴۴۰ × ۹۰۰ و گوشی ۳۷۵ × ۸۱۲.

ساخت: `node scripts/ui-shots.mjs` روی دادهٔ نمونه (یک «کار» و یک «رخداد» نمونه). صفحه‌هایی که نسخهٔ ویندوز نشان نمی‌دهد — ورود با حساب سازمانی و «ورود خودکار با حساب ویندوز»، راه‌اندازی نخست سرور و «سلامت سرور» — با پاسخ‌های ساختگی همان API در Playwright گرفته شده‌اند (یک منبع اکتیو دایرکتوری، نشانی یک‌بارمصرف راه‌اندازی، چهار فرایند سرور).
