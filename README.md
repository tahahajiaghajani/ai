# Task Flow

اپلیکیشن **تسک‌دهی، پیگیری و انجام خودکار کارها با ایجنت‌های هوش مصنوعی** — فارسی، راست‌چین، برای دسکتاپ و موبایل. یک اپ مشترک (یک Vercel و یک Supabase) که هر کاربر با **کلیدهای هوش مصنوعی و مخزن GitHub خودش** از آن استفاده می‌کند.

- **حالت ساده** (بدون هیچ نصب): به هر کسی تسک بدهید (فیلد «مسئول»)، تسک‌هایی که به شما سپرده شده را ببینید و وضعیتشان را دستی به‌روز کنید، و تسک‌هایی که به دیگران داده‌اید را دنبال کنید.
- **تجربه‌ی کامل**: با یک کلیک فعال می‌شود؛ کلید Claude / Google AI Studio / ChatGPT / Kimi / NVIDIA / OpenRouter را برای هر مرحله وصل می‌کنید، پیش‌کار و کار اصلی با ایجنت‌ها انجام می‌شود، و با وصل کردن GitHub، پروژه‌های کد و سند، دانش و گراف هر پروژه در **مخزن خصوصی خودتان** نگه داشته می‌شود.
- **از موبایل**: «در پروژه renew فایل audit.cs باگ دارد» را بنویسید؛ پروژه و فایل خودکار پیدا، اصلاح و در GitHub ثبت می‌شود.

## قابلیت‌ها

- **تسک‌دهی به هر کسی** با فیلد «مسئول»؛ «کارها» (سپرده به من / داده‌شده توسط من)؛ پذیرش، برگشت، شروع، اعلام انجام، تایید یا رد خاتمه
- **اتصال‌های شخصی**: هر کاربر کلیدهای خودش را وصل می‌کند (رمزنگاری AES-256-GCM، هرگز به مرورگر برنمی‌گردد) و برای پیش‌کار، کار اصلی و دانش، اتصال و مدل جدا انتخاب می‌کند
- **فقط پرامپت و فایل جدید شما** به مدل فرستاده می‌شود (نه عنوان و شرح تسک)
- **مجری داخل اپ** با ابزار (فهرست، جستجو، خواندن، نوشتن، ویرایش، حذف فایل) روی هر مدل؛ یا **Claude Code** روی GitHub Actions مخزن خودتان
- **پروژه‌ها**: افزودن فایل، پوشه، zip یا یک مخزن GitHub (مثلاً اپ ذخیره‌شده از Google AI Studio)؛ فایل‌ها **کامل و بدون تکه‌تکه شدن** ذخیره می‌شوند؛ نقشه‌ی فایل‌ها و یک **فایل دانش** که بعد از هر کار به‌روز می‌شود
- **انتخاب پروژه و فایل‌ها** با کمبوباکس قابل جستجو هنگام ارسال (پیش‌فرض: بدون پروژه و بدون جستجوی دانش)
- **جریان زنده‌ی کارها** در خانه، لاگ زنده، **ایجنت‌ها و ورکفلوهای شخصی** با سازنده‌ی بصری (مراحل موازی و شرطی)، گراف دانش (نقشه‌ی فایل‌ها + graphify)
- **صف منصفانه‌ی چندکاربره**: لیمیت یک کلید فقط کارهای همان کاربر را متوقف می‌کند و پس از ریست خودکار ادامه می‌یابد
- **مدیریت (فقط مالک)**: سیستم (Vercel/Supabase، زمان‌بند، ظرفیت اجرا، ثبت‌نام)، کاربران، **اطلاعیه‌ی روزانه** برای همه، ارتقای خودکار اپ — و نظارت بر کار همه
- **راهنما** داخل اپ: شروع، چطور کار می‌کند، تازه‌ها
- منوی ساده با پنج بخش (خانه، کارها، پروژه‌ها، ایجنت‌ها، صف اجرا)، تیتراژ آغازین برند، تقویم شمسی، اعلان‌ها، PWA (نصب روی موبایل)، تم تیره/روشن
