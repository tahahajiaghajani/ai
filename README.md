# TaskFlow AI

اپلیکیشن **اتوماسیون و ارکستراسیون چندعاملی** کارها — فارسی، راست‌چین، برای دسکتاپ و موبایل.

تسک‌دهنده تسک ثبت می‌کند ← مدیر تایید می‌کند ← **ایجنت‌های Gemini** (LangGraph) درخواست و فایل‌های پیوست را تحلیل می‌کنند و یک **دستور کار کوتاه و کامل** (به‌همراه حداکثر چند فایل کمکی) می‌سازند ← **Claude Code** دقیقاً خروجی خواسته‌شده را می‌سازد ← پاسخ متنی و فایل‌های خروجی هر دو مرحله مثل یک **گفت‌وگو** در اپ نمایش داده و دانلود می‌شوند ← تسک‌دهنده خاتمه را تایید می‌کند. همه‌چیز **زنده** (گراف ورکفلو، لاگ فعالیت‌ها، فهرست کارهای Claude) و روی سرویس‌های **رایگان** (Vercel + Supabase + GitHub).

## قابلیت‌ها

- **ورکفلو زنده** با ۷ گره (در انتظار تایید ← صف پیش‌کار ← پیش‌کار ← صف کار اصلی ← کار اصلی ← تایید خاتمه ← خاتمه‌یافته)، تسک‌ها به تفکیک تسک‌دهنده، ورکفلوی کوچک پیش‌کار (تحلیل ← دستور کار ← فایل‌های کمکی ← انتشار) داخل گره‌ی پیش‌کار؛ گره‌ها قابل جابه‌جایی‌اند و فلش‌ها همیشه از سمت درست وصل می‌شوند (چیدمان «دو ردیف» یا «یک خط»)
- **لاگ زنده** مثل Claude Code («اجرای دستور…»، «ایجاد فایل…»)، افکار Gemini و فهرست کارهای Claude
- **گفت‌وگوی تسک**: هر ارسال به Gemini یا Claude با پرامپت و فایل‌هایش، و پاسخ متنی AI همراه **فایل‌های خروجی قابل مشاهده و دانلود** (فایل‌های سیستمی مثل manifest و جلسه نمایش داده نمی‌شوند)؛ پیام تکمیلی به Claude از همان‌جا
- **انتخاب مدل Claude، effort و حالت thinking** در تنظیمات (پیش‌فرض) و برای هر ارسال؛ Gemini به‌صورت خودکار جدیدترین مدل Flash رایگان را به کار می‌برد و با تمام شدن سهمیه‌ی روزانه‌ی هر مدل، مدل بعدی را
- **پنجره‌ی تسک در ورکفلو**: دیدن، دانلود، حذف و بارگذاری فایل‌های تسک، ویرایش عنوان و شرح، و افزودن پرامپت و فایل خودتان درست قبل از ارسال به پیش‌کار یا Claude
- **تصویر پروفایل** برای هر کاربر (هنگام ثبت‌نام یا بعداً از منوی حساب)
- **کارتابل** با تایید/برگشت و ارسال تکی یا گروهی به پیش‌کار و Claude، همراه با پرامپت و **هر نوع فایل** (پرامپت خالی = پرامپت پیش‌فرض تنظیمات)
- **تسک‌های مرتبط** (ادامه، توضیح، رد خاتمه) در ادامه‌ی همان چت Gemini و همان جلسه‌ی Claude
- **صف ترتیبی** برای Gemini و Claude با توقف خودکار در لیمیت و **ادامه‌ی خودکار** پس از ریست
- **پایگاه دانش (RAG)** با pgvector + جستجوی ترکیبی، استخراج خودکار دانش و بسته‌ی **NotebookLM**
- **گراف دانش (graphify)**: صفحه‌ی تعاملی فارسی که پروژه‌ها، تسک‌های مرتبط، فایل‌ها، دانش و گراف‌های graphify هر پروژه را با ارتباط‌هایشان نشان می‌دهد
- **ارتقای خودکار اپ** فقط با پرامپت (Claude Code → PR → پیش‌نمایش Vercel → انتشار و migration)
- **یادگیری**: بازخورد 👍/👎 روی پاسخ‌های گفت‌وگو و بهینه‌ساز خودکار پرامپت‌ها با نسخه‌بندی
- تقویم شمسی، اعلان‌ها، PWA (نصب روی موبایل)، تم تیره/روشن
