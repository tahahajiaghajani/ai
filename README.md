# TaskFlow AI

اپلیکیشن **اتوماسیون و ارکستراسیون چندعاملی** کارها — فارسی، راست‌چین، برای دسکتاپ و موبایل.

تسک‌دهنده تسک ثبت می‌کند ← مدیر تایید می‌کند ← **ایجنت‌های Gemini** (LangGraph) پیش‌کار را انجام می‌دهند: تحقیق، WBS، روش انجام، اجرای کارهای ساده ← **Claude Code** کار را تمام می‌کند ← خروجی با دیتا مپینگ دقیق در GitHub ← تسک‌دهنده خاتمه را تایید می‌کند. همه‌چیز **زنده** (گراف ورکفلو، لاگ فعالیت‌ها، فهرست کارهای Claude) و روی سرویس‌های **رایگان** (Vercel + Supabase + GitHub).

## قابلیت‌ها

- **ورکفلو زنده** با ۷ گره (در انتظار تایید ← صف پیش‌کار ← پیش‌کار ← صف کار اصلی ← کار اصلی ← تایید خاتمه ← خاتمه‌یافته)، تسک‌ها به تفکیک تسک‌دهنده، ورکفلوی کوچک ۸ مرحله‌ای داخل گره‌ی پیش‌کار
- **لاگ زنده** مثل Claude Code («اجرای دستور…»، «ایجاد فایل…»)، افکار Gemini و فهرست کارهای Claude
- **کارتابل** با تایید/برگشت و ارسال گروهی به پیش‌کار و Claude، همراه با پرامپت و **هر نوع فایل**
- **تسک‌های مرتبط** (ادامه، توضیح، رد خاتمه) در ادامه‌ی همان چت Gemini و همان جلسه‌ی Claude
- **صف ترتیبی** برای Gemini و Claude با توقف خودکار در لیمیت و **ادامه‌ی خودکار** پس از ریست
- **پایگاه دانش (RAG)** با pgvector + جستجوی ترکیبی، استخراج خودکار دانش و بسته‌ی **NotebookLM**
- **graphify** برای گراف دانش فایل‌های هر تسک
- **ارتقای خودکار اپ** فقط با پرامپت (Claude Code → PR → پیش‌نمایش Vercel → انتشار و migration)
- **یادگیری**: بازخورد روی خروجی ایجنت‌ها و بهینه‌ساز خودکار پرامپت‌ها با نسخه‌بندی
- تقویم شمسی، اعلان‌ها، PWA (نصب روی موبایل)، تم تیره/روشن
