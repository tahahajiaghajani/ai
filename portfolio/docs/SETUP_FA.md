# راه‌اندازی پورتفولیو (GitHub + Vercel + Supabase + Google AI Studio — همه رایگان)

پورتفولیو در پوشه‌ی `portfolio` همین مخزن است و یک پروژه‌ی مستقل Next.js به حساب می‌آید؛ به Task Flow، سایت پارس یا سلین وابسته نیست.

**بدون هیچ تنظیمی هم build می‌شود و بالا می‌آید.** هر قابلیت با تنظیم متغیر مربوط روشن می‌شود:

| قابلیت | نیازمند |
|---|---|
| همه‌ی صفحه‌ها، فارسی و انگلیسی، پرونده‌های پروژه | هیچ |
| دستیار هوش مصنوعی («از هوش مصنوعیِ طاها بپرسید») | `GEMINI_API_KEY` (بدون آن، دستیار پاسخ‌های ثابت می‌دهد و به فرم درخواست راهنمایی می‌کند) |
| میز درخواست هوشمند (ثبت، کد پیگیری، تریاژ هوش مصنوعی، گفتگو) | Supabase + `GEMINI_API_KEY` برای تریاژ |
| صندوق پنهان `/admin` | Supabase + `ADMIN_PASSWORD` و `APP_SECRET` |
| اعلان تلگرام یا بله برای هر درخواست | `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` |

---

## ۱. پایگاه داده (Supabase)

همه‌ی جدول‌ها با پیشوند `portfolio_` ساخته می‌شوند؛ پس **می‌توانید از همان پروژه‌ی Supabase اپ‌های دیگرتان استفاده کنید**.

1. در [supabase.com](https://supabase.com) وارد پروژه شوید (یا پروژه‌ی تازه بسازید).
2. **SQL Editor** → New query → محتوای فایل `supabase/migrations/20261025000000_portfolio.sql` را بچسبانید → **Run**. اجرای دوباره بی‌خطر است.
3. **Project Settings → API** (یا **API Keys**):
   - **Project URL** → متغیر `SUPABASE_URL`
   - کلید **service_role** (یا کلید Secret جدید `sb_secret_…`) → متغیر `SUPABASE_SERVICE_ROLE_KEY`

> کلید service_role فقط روی سرور استفاده می‌شود و هرگز به مرورگر نمی‌رسد. همه‌ی جدول‌ها RLS فعال و بدون Policy دارند؛ یعنی با کلید عمومی (anon) هیچ داده‌ای خوانده نمی‌شود، و تابع محدودیت نرخ فقط برای service_role قابل اجراست.

## ۲. کلید هوش مصنوعی (Google AI Studio، رایگان)

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key**.
2. کلید را در متغیر `GEMINI_API_KEY` بگذارید.

دستیار به‌ترتیب این مدل‌های رایگان را امتحان می‌کند و اگر یکی شلوغ یا تمام‌شده باشد سراغ بعدی می‌رود (هر مدل سهمیه‌ی روزانه‌ی جدا دارد): `gemini-3.5-flash-lite` ← `gemini-3.1-flash-lite` ← `gemini-3.6-flash` ← `gemini-3.8-flash`. با `GEMINI_MODELS` (جداشده با کاما) می‌توانید مدل‌هایی را جلوی این زنجیره بگذارید.

برای محافظت از سهمیه: هر بازدیدکننده ۲۰ پیام در ۱۰ دقیقه و ۸۰ پیام در روز، و کل سایت `AI_DAILY_LIMIT` فراخوان در روز (پیش‌فرض ۱۰۰۰).

## ۳. انتشار روی Vercel

1. [vercel.com/new](https://vercel.com/new) → مخزن `tahahajiaghajani/ai` را Import کنید.
2. **Root Directory** را روی `portfolio` بگذارید (مهم). Framework خودکار Next.js تشخیص داده می‌شود.
3. در **Environment Variables** این‌ها را اضافه کنید:

| نام | مقدار |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | نشانی نهایی سایت، مثلاً `https://taha-aghajani.vercel.app` (یا دامنه‌ی خودتان) |
| `SUPABASE_URL` | از مرحله‌ی ۱ |
| `SUPABASE_SERVICE_ROLE_KEY` | از مرحله‌ی ۱ |
| `GEMINI_API_KEY` | از مرحله‌ی ۲ |
| `ADMIN_PASSWORD` | یک رمز قوی برای صندوق `/admin` |
| `APP_SECRET` | یک رشته‌ی تصادفی بلند (مثلاً خروجی `openssl rand -hex 32`) |
| `TELEGRAM_BOT_TOKEN` · `TELEGRAM_CHAT_ID` | اختیاری؛ مرحله‌ی ۵ |
| `TELEGRAM_API` | اختیاری؛ `bale` برای ارسال از طریق بله |
| `AI_DAILY_LIMIT` | اختیاری؛ پیش‌فرض ۱۰۰۰ |
| `GEMINI_MODELS` | اختیاری |
| `CRON_SECRET` | اختیاری؛ یک رشته‌ی تصادفی |

4. **Deploy**. هر push بعدی به `main` که پوشه‌ی `portfolio` را تغییر دهد دوباره منتشر می‌شود.

> **بیدار ماندن Supabase رایگان:** پروژه‌های رایگان پس از یک هفته بی‌فعالیتی متوقف می‌شوند. `vercel.json` یک cron روزانه دارد که `/api/keepalive` را صدا می‌زند و یک کوئری سبک اجرا می‌کند. اگر `CRON_SECRET` را تنظیم کنید Vercel آن را خودکار به‌عنوان Bearer می‌فرستد و درخواست‌های دیگر رد می‌شوند.

## ۴. صندوق پنهان (`/admin`)

- نشانی: `https://<سایت>/admin` (در منو نیست و `noindex` است).
- ورود با `ADMIN_PASSWORD`؛ نشست هفت روز معتبر است و با `APP_SECRET` امضا می‌شود.
- **درخواست‌ها:** هر درخواست با کد `TA-XXXXXX`، خلاصه و اولویت هوش مصنوعی، پیش‌نویس پاسخ و گفتگو با بازدیدکننده. وضعیت را عوض کنید (جدید، در حال بررسی، پاسخ داده شد، زمان‌بندی شد، بسته) یا «تحلیل دوباره» بزنید.
- **گفتگوها:** گفتگوهای دستیار، با علامت پاسخ‌هایی که دستیار نمی‌دانست.
- **دانش:** واقعیت‌های تازه‌ای که دستیار باید بداند (پروژه‌ی جدید، در دسترس بودن، دوره‌ها). دانش اصلی دستیار از خود محتوای سایت ساخته می‌شود؛ این‌جا فقط چیزهای اضافه را بنویسید.

## ۵. اعلان تلگرام یا بله (اختیاری)

1. در تلگرام با [@BotFather](https://t.me/BotFather) یک ربات بسازید و توکن را در `TELEGRAM_BOT_TOKEN` بگذارید.
2. به ربات پیام بدهید، سپس `https://api.telegram.org/bot<TOKEN>/getUpdates` را باز کنید و `chat.id` را در `TELEGRAM_CHAT_ID` بگذارید.
3. برای **بله**: ربات را در بله بسازید، توکن و شناسه را به همین شکل بگذارید و `TELEGRAM_API=bale` را اضافه کنید.

از این پس هر درخواست تازه و هر پاسخ بازدیدکننده با خلاصه‌ی فارسی هوش مصنوعی برایتان فرستاده می‌شود.

## ۶. افزودن یا ویرایش پروژه‌ها

- هر پروژه یک فایل در `src/content/projects/` است (فارسی و انگلیسی کنار هم) و در `src/content/projects/index.ts` به فهرست اضافه می‌شود؛ ترتیب همان ترتیب نمایش است. `tier: "lab"` پروژه را از ریل اصلی بیرون می‌برد و فقط در فهرست کامل نشان می‌دهد.
- تصویرها در `public/media/work/<پروژه>/` (WebP، عرض حداکثر ۱۹۲۰) و ویدئوها H.264 بدون صدا با پوستر.
- دستیار هوش مصنوعی پروژه‌ی تازه را خودکار یاد می‌گیرد؛ دانشش از همین فایل‌ها ساخته می‌شود.
- پیش از push: `npm run typecheck` · `npm test` · `npm run build` (آزمون‌ها کامل بودن هر دو زبان و وجود همه‌ی فایل‌های رسانه را بررسی می‌کنند).

## ۷. اجرای محلی

```bash
cd portfolio
npm ci
npm run dev          # http://localhost:3000 و http://localhost:3000/en
```

برای دستیار و درخواست‌ها، یک فایل `.env.local` از روی `.env.example` بسازید.
