# Portfolio — notes for Claude

Standalone Next.js 16 app in the `portfolio/` folder of this repository (its own Vercel project, Root Directory `portfolio`). Persian (RTL) at `/`, English at `/en`: two root layouts in route groups `(fa)` and `(en)`; page bodies are shared components that take `lang`. Read `README.md` and `docs/SETUP_FA.md` first.

- **Content** lives in `src/content/` with `{ fa, en }` pairs (`L` type). Case studies are one file each in `src/content/projects/`, registered in `index.ts`. Taha's own products (Siraf, Kariz) are in `src/content/products.ts`: one home-page section each (id = slug), the web version linked live and every other edition **locked** (no `href`; never link installers or GitHub Releases — visitors contact Taha). Blog posts are one file each in `src/content/blog/`, registered in `index.ts`, same slug in both languages; the people in event photos are never named. **Credit (the owner's rule):** the public site never names Claude, Claude Code or Anthropic, and never credits an AI tool or "AI-assisted engineering" for the work — roles and notes credit Taha (a test enforces the names). Other people's real work stays credited (Pars's team, the Sharif students, a client's own logo and photos), and nothing claims the opposite ("written by hand", "without AI"). Simulated or planned results are labelled; client confidentiality notes stay. Never publish bank hostnames, staff names, internal URLs, private repos or other people's data.
- **Design:** black and white only — tokens in `src/app/globals.css` (`bg`, `fg`, `fg-2`, `muted`, `faint`, `line`, `bg-2`; `.tone-invert` for inverted bands; `.mono-media` for pictures that turn colour on hover). Never raw colours in components. Fonts: Vazirmatn (fa), Inter Tight (latin), Instrument Serif italic accents, JetBrains Mono labels. No letter-spacing on Persian; animate Persian by line or word, never by letter.
- **Mark:** `src/components/brand/mark-paths.ts` (Hamzad, one stroked path on a 512 grid). Icons in `public/` are rendered from it.
- **Motion:** declarative attributes handled by `src/components/fx/motion.tsx` (`data-fade`, `data-split`, `data-parallax`, `data-scrub-words`, `data-reveal` + `data-reveal-inner` for pictures); everything respects reduced motion. Custom CSS classes go in `@layer components` so utilities win.
- **AI:** `src/lib/ai/` (Gemini REST + SSE, model chain), `src/lib/knowledge.ts` builds the assistant's knowledge from the content (plus `knowledge.md` in the data repository), `src/lib/retrieval.ts` (Persian BM25). Markers `[[work:slug]]`, `[[product:slug]]`, `[[post:slug]]`, `[[action:ticket]]`, `[[action:contact]]`, `[[unknown]]`.
- **Data:** no database. One private GitHub repository (`GITHUB_TOKEN` + `GITHUB_REPO`, client in `src/lib/github.ts`): requests are issues (`src/lib/request-issue.ts`: readable summary + hidden base64 JSON block, messages as marked comments, unmarked comments = private notes), panel settings in `settings.json` (`src/lib/settings.ts`, secrets AES-GCM encrypted with `APP_SECRET`), extra knowledge in `knowledge.md`, unanswered questions on one issue. Anything with visitor data goes through `assertPrivateRepo()`. Rate limits are in-memory per instance. The panel's **Connections** page (`/admin/connections`, `src/lib/connections.ts`) checks and configures everything.
- **Vercel:** `vercel.json` holds the Ignored Build Step (it overrides the dashboard). Keep its `git cat-file -e` guard: Vercel's clone is shallow, and when the last deployed commit is missing `git diff` exits 128, which Vercel counts as a failed deployment, not a build.
- Commands: `npm run typecheck` · `npm test` · `npm run build` (must pass with no env vars).
